# Atari Terror Creatures

Prototypes for the Atari Terror Creatures fan experience, the official website preview, and the merch shop preview.

- `at-creatures-prototype/` — responsive fan creature generator (desktop and mobile)
- `work-web-preview/` — Atari Terror website preview
- `at-shop-preview/` — merch shop preview

Open `at-creatures-prototype/index.html` in a browser to use the generator.
